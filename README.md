# TNT Cannon

The TNT Cannon is a Minecraft plugin that allows players to craft and use a cannon made of black wool blocks and a stone button. The cannon requires gunpowder and TNT in the player's inventory to shoot. When activated, the cannon fires a fireball projectile with TNT explosive damage, with a maximum range of 100 blocks. The fireball is launched from the front block of the cannon.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload the server to enable the plugin.

## Use

1. Craft the cannon by placing three black wool blocks in a row with a stone button at the end.
2. Ensure you have gunpowder and TNT in your inventory.
3. Right-click the stone button to shoot the cannon.
4. The fireball will be launched from the front block of the cannon, dealing TNT explosive damage to any blocks or entities it hits.
